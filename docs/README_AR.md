# SAVOURY — التطبيق الكامل الموحد

هذه الحزمة تحول مراحل المشروع إلى **تطبيق واحد قابل للتشغيل**: واجهة Mobile-first + Backend Node.js + SQLite.

## التشغيل
1. ثبّت Node.js 18+.
2. افتح مجلد المشروع.
3. نفذ `npm install`.
4. نفذ `npm start`.
5. افتح المتصفح على `http://localhost:3000`.

## الوحدات الموجودة
الموظفون، المخازن، المبيعات، المشتريات، محتوى الشركة، الإشعارات، التحليلات والتقارير، مع تسجيل دخول وصلاحيات أساسية وسجل تدقيق.

## ملاحظة مهمة
هذه **نسخة تشغيلية موحدة MVP/أساس إنتاج** وليست نسخة متجر Android/iOS موقعة نهائياً. النشر الفعلي يحتاج خادم إنتاج، قاعدة بيانات إنتاج، أسرار آمنة، بناء Android/iOS واختبارات قبول.
